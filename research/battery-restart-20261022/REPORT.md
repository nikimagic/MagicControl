# Нижний порог батареи и системный трей —0.1.135

## Запросы владельца и отменённая часть

Добавить справа в заголовке батареи общий numeric control
«Возобновить заряд ниже [N] %», сохранять выбранное значение вместо
зашитых97/80 и вернуть меню трея Windows к системному виду.
Отдельно предложенное изменение платформ7/4 отменено владельцем:
код выбора платформ/allowlist/команд7C3 не расширялся. Honor остаётся
на собственном HWMI/sysfs, без адресов/флагов Uniwill.

## Реализация

- Общая placeBatteryRestart в Geometry.h измеряет подпись текущим
  ClassicBody/языком/DPI; поле22DIP высотой, стрелки14DIP, единица% справа.
  Карточка/scroll height не увеличены. Заголовок использует оставшуюся ширину.
- Windows использует NumericFieldWindows и тот же шрифт body, без
  нового renderer. Стрелки применяют значение после native шага;
  ввод применяется при выходе из поля. Используется существующая очередь
  SettingsPage/DeviceOperation, запрет preview и доступность реального backend.
- GTK использует createNumericField и ту же Geometry; ввод применяется
  при выходе из поля. Без реального Linux backend control недоступен.
- Новый ключ ChargeRestart; запись INI атомарно объединяет только этот ключ
  после подтверждённого hardware readback. Начальный draft20 не отправляется
  в устройство автоматически. После опроса отображается actual lower.
- Кнопки верхнего предела используют сохранённый lower своей модели;
  без нового ключа сохраняется старое поведение, а не подстановка20.

## Границы моделей

### Wujie X5SP4NAG

applyBatteryChargeLimit получил необязательный lower. Сохраняются identity,
capability, platform/ROM pin, свежий RMWlow7, WMI upper, проверка согласованности,
финальный readback и owned rollback. По умолчанию используется выбранный
ChargeRestart или прежний97. Existing startup/resume API получает этот же ключ.
В поле допустим1–99;97 остаётся старым экспериментальным значением.
Назначение lower в точной EC firmware по-прежнему не подтверждено физическим
restart. Пересечение lower97/upper10 не объявляется доказанной гистерезисной парой.

### GM6IR0C / HYDROC

Используется существующий NativeBatteryController и прежние независимо
ограниченные transports. Lower1–95 и строго ниже upper. Пресеты upper100/95/85
без нового ключа продолжают использовать80. Отдельный setter lower сохраняет
точный raw upper, включая0/100 encoding, firmware-ownedbit7 и контекст7A6/7C3/770.
Изменившийся upper до первой записи отменяет операцию. При неудаче сохраняется
прежний парный owned rollback; соседние биты не стираются.
Только явно выбранный lower сохраняется/восстанавливается existing worker.
Retry разрешён только до записи; предшествующая операция native policy
исключает retry при последующем отказе lower. Пресеты upper здесь по-прежнему
не стали автоматически сохраняемыми выборами из-за добавления lower.

### Honor HLYL-WXX9

UI вызывает только существующий setChargeThresholds(start,end), с его
стабильным чтением и owned rollback. Редактирование start сохраняет end.
При native0/0 сначала нужно выбрать верхний предел; lower не активирует
неизвестную защиту. Без отдельного сохранённого lower остаются прежние
95/100,90/95,80/85. После выбора lower20 верхние кнопки передают20/end,
если пара допустима. Нет нового EC/WMI endpoint, таймеров, портового доступа
или вмешательства в клавиатуру Honor. Сохранение firmware retention остаётся
прежним; unsolicited host restore для Honor не добавлен.

## Файлы настроек

- Wujie: device-settings.ini
- GM6: gm6ir0c-device-settings.ini
- HYDROC: hydroc16g2-device-settings.ini
- Honor: hlyl-wxx9-device-settings.ini

Пути выбираются whitelist-helper по точному profileId; неподдержанный ID
не получает файл/команду Wujie. Старые файлы без ChargeRestart читаются как раньше.

## Трей

Только tray menu переведён с ControlTheme::trackPopup на стандартный
TrackPopupMenuEx. Пункты, callbacks и команды сохранены. DPI скрытого owner
по-прежнему совпадает с монитором anchor. Системный шрифт трея — явное
позднейшее исключение пользователя; остальные элементы используют Noto.
