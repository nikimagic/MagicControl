# Архив исследований SensorProbe и EC

Исходные скрипты и отчёты находятся здесь. Сырые данные, включая снимки,
журналы, настройки и выводы запусков, сохранены в `out/test_util/analysis/`
от корня проекта с прежними относительными именами. Результаты SensorProbe
находятся в `out/test_util/logs/`. Повторный анализ записывает результаты в
`out/test_util/generated/`, не меняя сохранённые исходные данные.

Исторические отчёты и журналы могут содержать прежний путь
`tests/test_util/analysis/`. Для файлов исходного кода и отслеживаемых отчётов
его текущая замена — `research/test_util/analysis/`; для остальных сохранённых
данных — `out/test_util/analysis/`. Полная локальная карта по каждому файлу и
проверка SHA-256 находятся в `research/workspace-audit-20261106/inventory/`,
файлы `test-util-analysis-before.csv`, `test-util-analysis-after.csv`,
`analysis-final-move-before.csv` и `analysis-final-move-after.csv`.

Некоторые исторические скрипты выполняют аппаратные операции. Не запускайте
их без отдельного осознанного решения и проверки соответствующего устройства.
