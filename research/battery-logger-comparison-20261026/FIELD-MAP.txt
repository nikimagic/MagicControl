Полный состав регистров батарейного логгера. 26.10.2026
103 описания: WUJIE62, GM6 основные 27 + CURRENT_CALC14.
Полный охват полей НЕ означает полную расшифровку прошивок. Неизвестное явно отмечено.

WUJIE 0x400 / 2byte LE / XIF0_capacity_unit
  Смысл: Единицы XIF0. Основание: Контракт ACPI/декодера.
  Граница: Определяет допустимость интерпретации ёмкости/показателя тока. Наши exact decoders принимают 1; после сброса 0 не объявляется автоматически подтверждённым mWh. Отсутствие literal DPTR0400 не отменяет документированный XIF0.

WUJIE 0x402 / 2byte LE / design_capacity_mAh
  Смысл: Проектная ёмкость. Основание: ACPI + единицы XIF0.
  Граница: Сырые counts. мА·ч только при подтверждённых единицах; это не остаток и не заданный ток.

WUJIE 0x404 / 2byte LE / full_capacity_mAh
  Смысл: Полная ёмкость. Основание: ACPI + единицы XIF0.
  Граница: Оценка полного заряда; full/design даёт расчётную оценку здоровья. Не независимое измерение физического износа.

WUJIE 0x436 / 2byte LE / remaining_capacity_mAh
  Смысл: Остаточная ёмкость XST2. Основание: ACPI + единицы XIF0.
  Граница: Сырые counts, возможны ограничения/подстановка firmware. Не подменять ею SOC из другого источника/момента.

WUJIE 0x432 / 2byte LE / battery_state
  Смысл: Состояние XST0. Основание: ACPI + собственные EC пути.
  Граница: Отдельно от модуля тока: low2=1 разряд,2 заряд,0 idle,3 противоречие. Bit2 критический статус. В GM6 возможен idle без обнуления 434; слово не является прямым CHARGE_EN.

WUJIE 0x434 / 2byte LE / current_magnitude_mA
  Смысл: Опубликованный модуль present rate XST1. Основание: ACPI + source trace по платам.
  Граница: При XIF0=1 — модуль тока мА; знак брать из 432, не из unsigned слова. GM6v1.12 публикует abs050A; коэффициент 34 из selected calculation branches не переносить на WUJIE.

WUJIE 0x438 / 2byte LE / voltage_mV
  Смысл: Напряжение XST3. Основание: ACPI + EC publication.
  Граница: мВ; V=raw/1000. Это измерительное/опубликованное значение, отлично от 030E/0522 и команды 15.

WUJIE 0x4A2 / 2byte LE / temperature_dK
  Смысл: Опубликованная температура батареи. Основание: WUJIE own publication.
  Граница: LE deci-K -> raw/10-273.15. При !BSOK firmware публикует default0B72 (19.85C); готовность обязательна. Полный путь зависит от 497.0; не всегда прямое чтение SBS Temperature.

WUJIE 0x4A4 / 2byte LE / BMS_current_mirror?
  Смысл: Альтернативная публикация тока. Основание: WUJIE bank1 AE43..AEE1.
  Граница: abs внутреннего 050E через 0A45/46, со своими guards/clamps; при idle путь может обнулить эту публикацию. Название BMS_current_mirror? не доказано; не смешивать с 434 или OS Rate.

WUJIE 0x4A6 / 2byte LE / cycles
  Смысл: Счётчик циклов. Основание: DSDT/OEM по платам.
  Граница: Не SOC, не таймер зарядки. FFFF недостоверно; замена батареи может менять cycles, без вывода о порче EC.

WUJIE 0x4AB / 1byte LE / SOC
  Смысл: SOC, опубликованный EC. Основание: Собственный WUJIE decoder/firmware compare.
  Граница: Целое 0..100; процентная ветка сравнивает его с 7B9.low7. Значение не является измерением текущей ёмкости с точностью до процента.

WUJIE 0x490 / 1byte LE / battery_status_bits
  Смысл: ACIC/BPST/BSOK и внутренние статусы. Основание: DSDT + EC state machine.
  Граница: Bit0 AC,bit1 основная батарея,bit2 готовность. WUJIE bit3/7 обслуживают выбор/разрешение основной/альтернативной зарядной ветви; это не измеренный поток тока.

WUJIE 0x497 / 1byte LE / ISDB_and_other_bits
  Смысл: ISDB и другие статусы. Основание: DSDT + разделённые native ветви.
  Граница: Bit0 выбирает отдельный протокол/расчёт батареи. На поле опирается ACPI подстановка ёмкостей; имя ISDB не доказывает физический тип BMS. Остальные биты отдельно не расшифрованы полностью.

WUJIE 0x49F / 1byte LE / adapter_class
  Смысл: ADPT: упакованный класс адаптера. Основание: DSDT/OEM.
  Граница: Не измеренная мощность потребления и не фактический ток на разъёме.

WUJIE 0x74C / 1byte LE / power_input
  Смысл: BIOS Project selector / status. Основание: Own CC codec + valid dumps.
  Граница: Low6 при 7CA.0=1 выбирает BIOS_PROJECT_ID. Подпись power_input у WUJIE logger неточна: это не просто байт питания. High bits имеют отдельную роль.

WUJIE 0x7A5 / 1byte LE / HIGH_POWER_OVERBOOST?
  Смысл: Смешанные служебные флаги. Основание: Own WUJIE EC.
  Граница: Bit2/4 формируются из 9063 в input-source routine; bit3 — thermal latch CPU43E>=95 или 44F>=85, снимается при обоих<=80. Имена HIGH_POWER/OVERBOOST/LIGHTBAR не являются доказанными универсальными значениями.

WUJIE 0x7A6 / 1byte LE / voltage_policy_DYN_TEMP?
  Смысл: Режим native защиты + прочие флаги. Основание: Own WUJIE and GM6 EC.
  Граница: Bits5:4 — поле 00/10/20. Balanced задаёт минимум 100 мВ/элемент,Healthy200; старшие aging guards могут усилить снижение. Это напряжение, не процент SOC. Отсутствие 741.0 снимает mask30. Bit1 DYN_TEMP из чужого OEM на эту плату не доказан.

WUJIE 0x7AB / 1byte LE / BIOS_power_profile?
  Смысл: Смешанный preset/config context. Основание: WUJIE selected literal consumers.
  Граница: Есть bit0 predicate и разбор нескольких битов в power logic. Нельзя весь байт называть единственным индексом BIOS-профиля без полного codec.

WUJIE 0x742 / 1byte LE / battery_gate_priority?
  Смысл: Capabilities + gate процентной ветки. Основание: WUJIE exact EC.
  Граница: Bit2 выставляется/снимается firmware по platform4 OR ROM770=4. Bit5 устанавливается startup-кодом; одно это не доказывает действующую ChargingPriority. Не писать в status вручную.

WUJIE 0x7B9 / 1byte LE / upper_and_Reached
  Смысл: Upper low7 + Reached bit7. Основание: Own percent and stop paths.
  Граница: Предел и статус, не самостоятельный CHARGE_EN. Gate закрыт ->Reached очищается. Разобранная native процентная ветка снимает Reached ниже того же upper; нижний restart95/90 этим не доказан.

WUJIE 0x7D0 / 1byte LE / lower_threshold_role?
  Смысл: Host/OEM parameter, native роль не установлена. Основание: Own source/census negative scope.
  Граница: Setter Down существует в OEM. В WUJIE DSDT имя DBD1, direct literal07D0 отсутствует в трёх исследованных EC. Ни имя Down, ни маска 7F не доказывают restart90. DBD1 и направление generic/indirect accesses требуют отдельного разбора.

WUJIE 0x7C3 / 1byte LE / platform
  Смысл: OEM platform selector. Основание: BIOS writer + EC predicates.
  Граница: Целый байт, не набор battery flags. Влияет и на другие подсистемы. Наблюдаемые 4/7/13 не равны автоматически заводской конфигурации.

WUJIE 0x7CC / 1byte LE / charger_priority_bits?
  Смысл: Статус источников питания и TCSA. Основание: DSDT WUJIE + own EC.
  Граница: Bits0/1/2 DC0C/TC1C/TC2C,4/5 TC1P/TC2P,7 TCSA. Bit7 зеркалируется в 984.7 и участвует в пересчёте input context. Не универсальный прямой запрет зарядки.

WUJIE 0x7CD / 1byte LE / TypeC_rating_A

WUJIE 0x7CE / 1byte LE / TypeC_rating_B

WUJIE 0x30E / 2byte BE / base_word?
  Смысл: Базовое желаемое напряжение BMS. Основание: Own WUJIE and GM6 native path.
