# INFO: сообщения операции, Custom255 и Esc

Поручения владельца25.10.2026: увеличить предупреждение с обрезанным путём;
автоматически показывать такое окно при операциях INFO; все сообщения от начала
до конца, общий scrollbar; Custom WUJIE до255 после проверки OEM byte setter;
Esc отменяет редактирование без применения.

Окно сообщений расширено до780DIP по ширине с рабочей высотой, ограниченной
экраном. Текст выделяемый и переносится в readonly multiline control. Native
scrollbar не добавлен: ScrollModel, отрисовка и wheel общие; pointer press/drag
из INFO вынесены в общий PageMechanics. Перенос строк не меняет пути в логах.

OperationMessages — shared transcript, потоки публикуют только данные; GUI
адаптеры забирают их пачками. Есть привязка по worker binding и action-ID,
без подмешивания других пользовательских действий. История не обрезается;
UI выборка ограничена размером пачки, не общим количеством сообщений. Вывод
сохраняется в открытом окне после завершения. Если пользователь ушёл вверх,
новые сообщения не должны принудительно перемещать его в конец.

Windows INFO подключает сбор сведений/EC/BIOS/VBIOS/подготовку и запуск PawnIO.
Тексты stdout/stderr vendor readers дополнительно читаются из уже существующих
raw-файлов; аппаратных запросов это не добавляет. После выхода установщика
фиксируются exit code и повторная OS-проверка установленной версии. Отмена
не убивает внешний мастер. В Linux сбор сведений перенесён в background worker;
EC/VBIOS используют тот же transcript, GTK окно — существующий scrolledWidget.
Неподключённые Linux BIOS/PawnIO не активируются.

Ограничение255 относится к прямому byte EC пути WUJIE. Исходный reference:
`C:/Users/admin/Documents/mechrevo/Decompiled/GCUService_Reference_w568w/GCUService/MyControlCenter/MyFanManager.cs`,
около2184: EcCtrl.Write(...,1923,(byte)PL1), аналогично PL2/PL4. В проекте
Performance.cpp отправляет только783–785. Прежние DC ceilings и прочие модели
сохраняются; это граница кодирования, не подтверждение допустимой мощности.
Esc отменяет только локальный редактор, восстановив значения до его открытия.
