Приоритетный порядок будущих исправлений (в этой ревизии код не исправлялся):

1. Wujie, P1: обычный Manual online пропускает проверку смены владения; автономный
   Manual на обычном5с опросе восстанавливает сброшенные флаги без sleep.
   FanControlWindows.cpp:585–609,1056; C# эталон CheckOwned каждый цикл.
   Разрешённый wake-rearm отдельно; не путать его с внешним владельцем.

2. GM6, P2: CPU пресеты SETs вызывают комплексный OEM setMode, останавливают
   online и переписывают FAN RAM (SettingsPage.cpp:1358, ControlWindows.cpp:283–289).
   Это действительно родной комплексный профиль, но противоречит общему правилу
   независимости SETs/FANs. README и общий контракт сейчас расходятся.
   Нужен отдельный CPU-only путь без переноса регистров Wujie на Intel.

3. Honor, P2: штатное disable0/0 блокирует battery controls; Linux rollback
   не подтверждается; watcher может сообщить Auto после отказа от чужих targets;
   FAN apply обходит общий DeviceOperation gate. H1–H4 вhonor.txt.

4. Достоверность исполнения/сохранения, P2:
   GM6 settled RPM ошибочно превращается в fanResponseConfirmed;
   gm6ir0c-power.txt записывается неатомарно и без проверки ошибки;
   Wujie battery rollback ошибка не доходит до UI, actual не перечитывается;
   ошибка APU restore блокирует независимый FAN restore.

5. Полнота диагностики, P2:
   HYDROC settings export не копирует hydroc16g2-device-settings.ini;
   HYDROC общие EC write counts0→0 — константы, не измерение всех writers;
   частичный успех Radeon скрывает второй OS-visible адаптер в vendor rows;
   Windows battery enumeration прекращается после первой system battery;
   Unknown не получает необходимую полную native EC/HID driver inventory.

6. Данные/сообщения:
   unknown AC source отображается/сохраняется какfalse=батарея;
   устаревшие Wujie power/battery samples могут выглядеть текущими;
   диагностический SSD primary получает SMART source при прежнем Storage value;
   часть ошибок HWMI/PawnIO теряет точный status/HRESULT;
   Intel HYDROC остаются ошибочные APU/SMU подписи.
   Исправления должны менять достоверность данных, сохраняя карточки Wujie.
