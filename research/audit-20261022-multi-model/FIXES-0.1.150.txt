MagicControl0.1.150 — исправления ревизии моделей,22.10.2026

1–2. Общий battery ROM-ID owner хранится в LocalAppData/MagicControl/DeviceState/<SMBIOS Type1 UUID>/<profile>-battery-romid-owner.txt. Формат v2 включает профиль и UUID. Смена portable-папки одного Windows-пользователя использует тот же файл. Чужой профиль/UUID не проходит проверку, неизвестный UUID не разрешает новую policy запись. Штатные EC маски и последовательности apply/readback/rollback не изменены.
Автомиграция разрешена только для уже привязанной v2 записи. Legacy04 без подтверждённого происхождения остаётся закрытым: подхватывать модельный файл на другой машине нельзя. Известная запись текущего Wujie перенесена отдельно после сверки exact SMBIOS платы и UUID текущего Windows RSMB с RSMB из дампа подтверждённого перехода141→149. Исходный legacy файл сохранён. Детали только локально: receipt-migration.json; процесс использовал Windows API/файлы, без ECIO.

3. SETs фиксирует BoardDescriptor при создании; lightingPreferences/подписи/максимум яркости не следуют глобальному preview. OEM яркость маршрутизируется в реальную сохранённую страницу, когда открыта другая модель. Никаких EC чтений/записей в обработчике уведомления не добавлено.

4. Общий keyboard OSD принимает maximum. Honor получает2, прежние Uniwill4. Системные события используют тот же formatter. Геометрия, шрифты, DPI не изменены; Linux использует общий код.

5. Общая PawnIO setup policy различает Install/Upgrade/Repair/Current/UnknownVersion. Сравниваются четыре числа статического SYS VERSIONINFO с bundled2.2.0.0. Старой версии доступно обновление; stopped той же версии — штатный мастер восстановления. Более новый драйвер не предлагается заменить старым. Неизвестная версия обозначается отдельно и не запускает setup. Политика используется до подготовки, на кнопке и перед запуском. Подпись/hash/интерактивный мастер сохранены. Новые UI подписи переведены на четыре языка.

6. GM5 получает собственные AMD SPL/SPPT/FPPT и model ID в SETs журнале, readback error, RGB status и battery metadata/status/source. Общий декодер допускает описательное имя модели; арифметика/регистры не менялись. GM5 7D0 подписан DBD1, не lower restart. GM6 сохраняет Intel PL1/PL2/PL4. Канал gm6ir0c означает общий модуль реализации и не переименован повсюду ради модели.

Проверки/границы: общий Release Windows/Linux Tools/Build-All.ps1; версии/SHA256 portable по product-build.json и VERIFICATION-0.1.150.json. Аппаратные/UI тесты не запускались и не добавлялись, EC помощником не читался/не записывался. Контроллеры FANs, таблицы, протоколы и реальные лимиты этим исправлением не переписывались. На всех физических ноутбуках поведение после патча ещё не измерено. Предупреждения компилятора в существующих unrelated участках остаются вне этих шести исправлений.
