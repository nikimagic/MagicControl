Поручение пользователя20.10.2026 — единые процентные пороги батареи

Эталон: существующий Wujie X5SP4NAG. Три верхних значения остановки зарядки:
100%,95%,85%. Нижний порог возобновления фиксирован80%. Это не запрос на
новые UI-поля произвольных порогов и не таблица native profile ->percent.

Проверить по отдельности пять профилей: Wujie, GM6IR0C, HYDROC-16 G2,
Honor HLYL-WXX9, Unknown. Работа разделена по модельным агентам; общий код,
UI и сборки интегрирует только корень после исследования. Одновременно
работают не более трёх агентов; остальные модели проходят следующей очередью.

Каждый отчёт должен разделять:
1. Запрос/сохранённую настройку.
2. Переданную команду/кодирование и точное устройство/версию.
3. Свежий readback верхнего/нижнего порога и режима выполнения.
4. Реальную остановку/возобновление зарядки по току/мощности/SOC во времени.

Для подключения нужны точный setter, enable/enforcement path, getter,
необходимые capabilities/guard, ограниченный owned rollback и описание
сохранения/восстановления. Совпадение адреса/драйверного API не даёт права
заимствовать platform4/7 или всю карту Wujie. Profiles7A6.4–5 сами по себе
не задают100/95/85. Значение в RAM без исполнения не объявлять применённым.

Агенты только изучают исходники/точные OEM/первичные материалы и пишут свои
отчёты. Не запускать GUI/CLI/OEM/тесты/сборки/установщики, не менять драйверы,
службы/EC/UEFI/SMU, INI или production-код. Дизайн карточек и скролл Wujie
сохраняются. Новые неподтверждённые writer paths не включать ради одинаковых
кнопок. Если метод не найден — назвать проверенную область и конкретно
недостающее свидетельство; не подменять требуемую функцию другой политикой.
