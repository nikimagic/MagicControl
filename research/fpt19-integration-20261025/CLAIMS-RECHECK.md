# Перепроверка BIOS readers всех16 моделей

25.10.2026, только сохранённые файлы/первичные описания. Никаких аппаратных запусков.

1. **AFU не универсален для AMD.** Подтверждено. [AMI](https://www.ami.com/resources/ami-firmware-utility-afu-a-secure-update-utility-for-aptio-v-uefi-bios-firmware/)
   описывает связь AFU с firmware/SMM/SMI интерфейсами Aptio. Сам CPU Ryzen не
   является достаточным условием. Наш код допускает AuthenticAMD плюс AMI BIOS,
   но это предварительный фильтр, не доказательство доступности SMI Flash:
   окончательный результат даёт vendor tool и проверка образов.
2. **WUJIE: два32МиБ AFU файла.** Пересчитаны оба сохранённых файла из
   bios-20261024-193321-0:33554432байта, полностью равны, SHA256
   2870a75a8c2518199cd9c572c3cd466d9f971b41bb047edbd3dda85ec6d2aaad.
   tool.json указывает AFU5.17.00.0153. Это подтверждённый сохранённый ROM capture;
   маркировка/физическая топология SPI этим не устанавливаются.
3. **GM5/L16: AMI, AFU не проверен.** Согласуется с сохранёнными inventory и
   точными README моделей. Нового успешного BIOS AFU capture не найдено.
4. **Остальные пять AMD: AFU требует проверки firmware.** Сохранить статус
   GM6BG0X/GX6HG0U-F/JIAOLONG X6DR55xx-B2/CANGLONG X6 и X8 как кандидат,
   не назначать AMI по сходству BIOS N.1 или по семейству Ryzen.
5. **Honor HLYL BIOS1.09 — Insyde.** Подтверждено по исходным байтам и
   сохранённому структурному разбору. Размер16777216байт, SHA256
   38597994dc39ed17d57cee8331ac107579b6ff186934cdbc873d3c5f363a806e.
   В0xEA8000 raw header начинается HFDM, parser выделяет Insyde H2O FlashDeviceMap
   и Insyde FDC store. Прежнее «производитель неизвестен» можно уточнить до InsydeH2O.
   README называет файл результатом H2OFFT -g; исходного stdout/журнала этого
   вызова в проверенной firmware-папке нет. Поэтому наличие16МиБ образа и его
   структура доказаны сильнее, чем точная историческая команда чтения.
6. **Honor нужен отдельный Insyde-путь.** Семейство инструмента правильное:
   OEM [H2OFFT](https://support.tq-group.com/en/x86/tqmxe40c2/bios/bios_tools)
   предусматривает backup BIOS. Но нельзя без разбора выбрать любую H2OFFT:
   версия конкретного historical reader/OEM config/параметры и драйвер ещё не
   установлены. В0.1.191 H2OFFT не встроен, Honоr не выдаётся за работающий AFU.
7. **FPT19 не заменяет16 на GM6.** Подтверждено на бинарниках.31 запись16.1
   по raw172EC0 содержит7A00–7A7F; GM6 LPC8086:7A0C входит.13 записей
   19.0.5.1948 по raw29EB60 не содержат7A0C. FUN14003C330 действительно
   проходит13 записей и проверяет vendor8086/internal platform/low-high ID.
8. **Четыре семейства, не гарантия всех16 экземпляров.** Для Windows разумно
   разнести FPT16, FPT19, AMI AFU и OEM Insyde H2OFFT. Сейчас подключены первые
   три с guard; четвёртый — отдельная будущая работа. Один бренд BIOS/CPU или
   одно имя чипсета не доказывают полный SPI/EC capture. Неизвестные конфигурации
   сохраняют отказ/partial и причину вместо подстановки неподтверждённого reader.

Точные вычисленные данные: audit-evidence.json. Они не требуют новых чтений ноутбука.
GUI из SSH запускается как GUI-процесс; терминальное управление требует отдельного
командного входа. Существующий Windows --dump-bios — специальный helper, не
полная консольная оболочка. Владелец отдельно поручил восстановить mctl после191.
