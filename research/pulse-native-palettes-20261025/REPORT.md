# Штатные цвета пульсации —25.10.2026

## GM6IR0C: соответствие найдено в оригинальном UI

Не перенос из WUJIE и не вывод по значению RGB в режиме Mono.
Из `build/research-gm6ir0c/battery-ui-resources/resources.pri` (штатный пакет
ControlCenter3 **5.52.50.23**) извлечён embedded SingleZoneKeyboardView.xbf:

- offset775312,6386байт;
- PRI SHA256 `4f3cb406bb937782feecfdcedbc69b420676d7466e061f0f3fd699a16bed80b2`;
- XBF SHA256 `71c8760128ab59eb7d7536fed4954cbc6b13cbb7e93e26320eaa75b507d9f361`.

Локальный XBF2.1 parser восстановил BreathingIndexPanel:

| Имя штатной кнопки | Fill ARGB | Цвет | Передаваемый индекс |
|---|---|---|---|
| B_1 | #FFFF0000 | Красный | 1 |
| B_2 | #FF008000 | Зелёный | 2 |
| B_3 | #FF0000FF | Синий | 3 |
| B_4 | #FFFFFFFF | Белый | 4 |

Связь UI с индексом дополнительно видна в оригинальном native обработчике
`SingleZoneKeyboardView.BreathingGrid_PointerPressed`: выбирается именованный
Grid, выделяется его border и из имени формируется BreathingIndex. PDB/дизассемблер
использованы только как файлы; OEM DLL не запускалась и не загружалась.

Активный сервис GM6 в
`build/research-gm6ir0c/all-active/020003A6-MyControlCenter.MyRgbKeyboard.SingleZone.cs`
содержит StartBreathingMode: чтение7C5, сохранениеbits3–7, подстановка1–4 вlow3.
В SetColorMode ветка эффекта2 передаёт только BreathingIndex; SetRGBColor и
UserDefineColor используются отдельной веткой Mono. Это основание ограничить
EC Pulse четырьмя штатными цветами, но не утверждение о независимом физическом
измерении каждого LED на пользовательском GM6.

## Различия ноутбуков

- **GM5HG0A:** embedded SingleZone XBF из его OEM5.52 имеет тот же SHA256.
  Подтверждена та же таблица1=red,2=green,3=blue,4=white.
- **WUJIE:** существующее подтверждение владельца сохранено отдельно:
  1=white,2=red,3=green,4=blue. Общая UI последовательность White/Red/Green/Blue
  остаётся прежней, но реально отправляемые индексы у GM6/GM5 и WUJIE разные.
- **MACHENIKE L16:** сервис знает индексы1–4, но актуальный WinUI5.60 ресурс
  не содержит B_1..B_4. Перенос названий цветов из другого пакета не доказан;
  сохраняется номерная палитра, без расширения аппаратного управления.
- **HYDROC ITE HID:** это другой протокол. OEM LightingConfiguration содержит
  effect и RGB; Breathing2 принимает RGB, в том числе собственный цвет. Нельзя
  объявлять его четырьмя зашитыми EC цветами по аналогии с GM6.
- **Honor/неподтверждённые модели:** эта EC палитра им не назначается.

## Кнопка «Свой цвет» и окончательное указание пользователя

Первоначальное указание скрыть её во всей пульсации отменено последующим
«оставь кнопку». Изменение видимости полностью отозвано. Кнопка остаётся на
месте: для Mono доступна; в EC Pulse не включает неподтверждённый произвольный
RGB. ITE HID сохраняет существующий рабочий RGB-путь в Breathing.

## Реализация и проверка

KeyboardPulsePalette задаёт GM6/GM5 по явным profile-ID: UI White/Red/Green/Blue
соответствует индексам4/1/2/3. Для WUJIE остаются1/2/3/4; неизвестные GM палитры
не получают чужие цвета. Существующий renderer уже рисует Pulse green#008000.
Размещение, размеры, scroll и аппаратный протокол не меняются. Linux использует
прежние недоступные native controls; нового Linux writer не добавлено.

XBF разобран открытым [XbfTools](https://github.com/chausner/XbfTools), ревизия
сохранена в xbf-tools-revision.txt. Перед локальным запуском проверены исходники
парсера; создан минимальный CLI без NuGet-пакетов. Конвертер только читал XBF
и записывал XAML. Известные ограничения конвертации не заменяются догадками:
цвета сопоставлены с явными B_1..B_4 и исходным обработчиком.

Ни MagicControl, ни OEM приложения, ни аппаратные читалки, EC/HID команды
при этой работе не запускались. Сборка/portable/SHA описываются отдельно в receipt.
