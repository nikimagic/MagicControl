# GM6: наблюдение пользователя выше OEM artwork

25.10.2026 пользователь уточнил: это GM6IR0C; четыре кнопки текущей0.1.204
дают физически синий, белый, красный, зелёный. До исправления UI отображал
White/Red/Green/Blue и отправлял4/1/2/3. Следовательно:

| Фактический цвет | Raw7C5.low3 |
|---|---|
| Белый | 1 |
| Красный | 2 |
| Зелёный | 3 |
| Синий | 4 |

Последнее указание: порядок кнопок как у WUJIE, физически назначить правильные
цвета. Поэтому общий White/Red/Green/Blue layout сохранён; только exact GM6
получает observed1/2/3/4 вместо OEM-artwork4/1/2/3. GM5's byte-identical OEM XBF
не доказывает ту же физическую прошивку, его прежняя таблица не изменяется.

Окончательное указание также отменило «оставь кнопку»: в Pulse picker скрыт,
включая ITE HID, обработчик заблокирован для Pulse. В Mono picker остаётся.
Аппаратный протокол, masks, сохранениеbrightness и геометрия не меняются.
Новых аппаратных запусков агент не выполняет. Проверка владельца — источник
физического соответствия; прежний REPORT.md сохраняется как история источников.
