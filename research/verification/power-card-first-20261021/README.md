# MagicControl 0.1.128 — производительность первой карточкой SETs

Общий SettingsCardContract задаёт порядок1/2/0: CPU/APU → подсветка → батарея
с диагностикой. Реальные Windows/GTK страницы используют одну Geometry и общую
модель. Native renderers не изменены; Geometry менялась только в комментарии,
числовые размеры/внутреннее расположение/обработчики остались прежними.
Карточка подсветки сохраняет компактную высоту110DIP из0.1.127.

Ожидаемый порядок в существующем offline-тесте обновлён. Тесты не добавлялись
и не запускались; приложение и аппаратные API не запускались. Живое окно не
проверялось. Выполнена общая Release-сборка Windows/Linux и static verification
версий/SHA реальных portable,465 входов,56 PE ресурсов,29 runtime исходников,
protected UI/command files,личных файлов и прошлых архивов. Фактические результаты
содержатся в verification-0.1.128.json. GitHub-пакеты не обновлялись.

Хэши личных файлов перед первым билдом сохранены в personal-before-build.json;
перед финальной заменой, после штатного выхода пользователя, — personal-before-staging.json.
Именно второй снимок сравнивается с результатом staging; личные файлы не перезаписывались.
