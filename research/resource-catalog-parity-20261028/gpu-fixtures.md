# Проверка наблюдаемых GPU

Автономный `magiccontrol_resource_catalog_tests` содержит три обезличенных примера значений из `FANs.presentation`:

- Wujie: `MagicControl/windows/logs_WUJIE_Series-X5SP4NAG/MagicControl-1.jsonl`, версия 0.1.253;
- Honor: `Users_logs/HONOR_HLYL-WXX9/20261027-160415-MSK/snapshot/logs_HLYL-WXX9-PCB/MagicControl-1.jsonl`, версия 0.1.240;
- HPBSD: `Users_logs/MINISFORUM_HPBSD/20261027-160415-MSK/snapshot/logs_HPBSD/MagicControl-1.jsonl`, версия 0.1.236.

Из каждого выбран первый event `source=FANs.presentation`. В фикстуры перенесены только имя GPU, нагрузка, мощность, температура, частота и подпись источника мощности; LUID, серийные номера и другие идентификаторы не перенесены. Тест создаёт синтетический `MonitoringSnapshot`, сравнивает наблюдаемую строку каталога и источник; не читает устройства и не управляет ими.

Эти журналы не содержат в этом событии полного снимка CPU/вентиляторов/батареи, поэтому фикстуры не доказывают полное соответствие каталога либо физическое исполнение команд. Дополнительные источники температуры/нагрузки/частоты в этом событии отсутствуют и не выдумываются.

Дополнительно тест содержит отдельные примеры из первых строк `sensors.jsonl` дампов `logs_WUJIE_Series-X5SP4NAG/dumps/dump-20261024-093815-0`, `HONOR_HLYL-WXX9/20261027-160415-MSK/snapshot/logs_HLYL-WXX9-PCB/ec-dumps/dump-20261027-122632-0` и `MINISFORUM_HPBSD/20261027-160415-MSK/snapshot/logs_HPBSD/ec-dumps/dump-20261026-184926-0`. Извлечены только температура и обороты соответствующих CPU/Dashboard GPU каналов с подписями источников. В Wujie RPM в этой строке отсутствует; у HPBSD второй канал подписан как системный вентилятор, не GPU. Это реконструированные выборочные данные диагностики, а не полное воспроизведение UI snapshot или подтверждение свежих данных железа.
