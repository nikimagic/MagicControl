# Общее журналирование, MagicControl0.1.181

Windows и Linux собраны Tools/Build-All.ps1, рабочие portable обеих ОС обновлены.
GUI/CLI SHA256 и версии сверены: portable-verification.json. Первый Windows
staging отказал из-за занятого EXE; пользователь закрыл приложение через трей,
повтор завершил тот же общий номер181. Тесты и приложения не запускались.

Общие ActionLog/ControlAudit, UI events и snapshots, correlation через
DeviceOperation/worker/очередь, команда/ответ/readback/error/rollback.
Подробности SingleZone, typed Huawei/Honor, native GM, HID, ACPI, PawnIO,
sysfs, NVML и BLE. Версия и фактическая плата/профиль в каждой обычной записи.
Подробный контракт и границы: docs/ACTION-LOGGING.md.

Сохраняются три пары логов без.part и отдельная история rom_id. Геометрия,
скролл, допуски моделей и аппаратные последовательности не изменены. Снимки
используют существующие данные, hardware IO ради журнала не добавлен. Runtime
hooks/все модели физически не проверялись; ACK не выдаётся за исполнение.

Новый запрос третьей политики7/FF получен во время этой сборки и выполняется
следующим изменением. В181 включён только завершённый аудит действий.
