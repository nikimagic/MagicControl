# Исправления по GM6 (16) и WUJIE portable,25.10.2026

Основания: `research/gm6ir0c-logs16-20261025/REPORT.txt`, сопутствующие сырые
события и `research/portable-audit-20261025/REPORT.md`. При реализации приложение,
драйверы и vendor readers не запускались; аппаратные команды не выполнялись.

- FPT16/19: фиксированное короткое имя выхода относительно уникальной папки
  дампа, абсолютный путь EXE сохраняется; cwd записан в лог. AFU/NVFlash путь
  и опции не менялись. На GM6 ошибка37 была на filename132символа; реальное
  чтение после исправления ещё предстоит проверить пользователю.
- NVIDIA: полный segment/BDF подтверждается NVML и уникальным OS devnode по
  B/D/F и VEN/DEV/SUBSYS. Domain0 и index0 не подставляются. Несовпадение или
  неоднозначность по-прежнему запрещают чтение. Повторный NVML poll устранён.
- GM6 Win Lock: OEM trigger767.0 не изменён; serialized минимальный интервал
  между командами2с и ожидание ACK до3с. Состояние перечитывается после ожидания
  и до отправки. Toggle отправляется один раз, повторов нет; при неподтверждении
  остаётся явная ошибка. Лог доказывает единичный OFF failure и позднейший успех,
  но не устанавливает причину firmware отказа: исправление timing требует
  аппаратного подтверждения. Другие модели сохраняют прежний polling window.
- Постоянные platform_id/rom_id: intent отделён от transport-returned; защитные
  чтения не создают ложные mismatch. Снимки политики читают пару, не повторяют
  три раза полный ROM tail; timestamp прежнего полного региона сохраняется.
- Общий JSON logger резервирует envelope keys на обоих ОС; конфликтные payload
  ключи получают префикс payload_, данные сохраняются, вложенный JSON не меняется.
  Производители BIOS/FAN исправлены отдельно, поля событий остаются плоскими.
- WUJIE: OS W/V/current сохраняются одним набором; EC supplement не подмешивает
  свой ток0мА к OS мощности32Вт. EC поток остаётся независимым.

UI геометрия, скролл, EC masks/ownership, состав flash/read-команд и настройки
пользователя не менялись. Build-All собирает GUI/CLI обеих ОС; без аппаратного
запуска результат не является подтверждением физического исполнения.
