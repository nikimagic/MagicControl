Подсветка GM6IR0C / сравнение профилей MagicControl
19.10.2026. Исследование файлов/кода, без аппаратных команд.

1. Текущий статус

Wujie X5SP4NAG: Windows RGB/яркость0..4/моно/пульсация/радуга реализованы.
HONOR HLYL-WXX9-PCB BIOS1.09: OFF/LOW/HIGH через PawnIO/I2EC, физически
подтверждены прежними журналами и владельцем. RGB-эффекты к нему не относятся.
Linux Honor использует доступный huawei-wmi sysfs, без переноса I2EC setters.
GM6IR0C: backlight capability пока false, SETs кнопки намеренно disabled,
состояние Gm6Controller не содержит подсветки. NoName не получает EC-допуск.

2. Точная OEM-цепочка GM6IR0C

Активный GCUService1.0.2.70 из пользовательского архива, файл:
build/research-gm6ir0c/samples/GCUService-active.exe
SHA256 8FD02BF5F42629998D8EC716C3E6FF906BAF73CB356B1FDD7585A26D77A49DAF.

37 ответов Keyboard/Status в samples/companion.log:
solution=EC и type=SingleZone во всех37; яркость встречается0,1,2,3,4.
SingleZonePowerSupport встречается true и false: нельзя считать ранний кеш
службы окончательным getter-результатом. Владелец подтвердил моно, пульсацию
и мульти/радугу на этом ноутбуке19.10.2026.

LM_Manager.LM_Init пробует ITE, затем EC. LM_EC_RGB проверяет0x766.bit2 и
выбирает SingleZone. HIDKeyboardFactory создаёт соответствующий SingleZone.
Рабочие тела методов находятся в SingleZone; многочисленные NEEDS IMPLEMENT
в LM_EC_RGB не означают отсутствие реального EC управления производной веткой.
SingleZone → MyEcCtrl → AcpiCtrl → существующий ACPIDriver. Оснований искать
новый клавиатурный драйвер для этой установленной EC-ветки не обнаружено.

Декомпиляция активного EXE сохранена в build/research-gm6ir0c/lighting-active/:

3. Команды, раскрытые активным OEM-кодом

Функция                  EC/маска/последовательность
RGB capability            0x766 &0x04; LM_EC_RGB.Init.
Питание подсветки          0x78C.bit1:1=disable,0=enable; соседние биты сохранять.
Яркость0..4               0x78C.bits7:5; bit4=strobe; SetBrightness_EC.
RGB каналы                0x769/0x76A/0x76B; уровни устройства0..50.
Применить статический RGB  0x767.bit5 после записи каналов; SetRGBLevel.
Радуга                    RGB=0/0/0, затем0x767.bit7=1; StartRainbowMode.
Выключить радугу           снять только0x767.bit7.
Пульсация                 0x7C5.bits2:0:0=off,1..4=штатные пресеты.
RGB по умолчанию           чтение0x76C/0x76D/0x76E.
SingleZonePowerSupport    0x78E.bit5; HIDKeyboard.GetSingleZonePowerSupport.

0x7C5 также содержит respective fan bit7. Любой backlight setter обязан
сохранить этот бит, а FANs — сохранить младшие биты пульсации. Прочие функции
разделяют0x767: запрещена запись всего байта вместо принадлежащей маски.

4. Эффекты и отличия от Wujie

SetColorMode:1=static,5=rainbow,2=breathing,64=manual colour cycle.
Static/breathing/rainbow используют EC. Manual cycle исполняется OEM Timer:
шесть настраиваемых индексов цветов, интервал ManualInterval*1000мс.
Он не является автономной аппаратной радугой.

OEM SingleZone содержит30цветовых пресетов и отдельную калибровку.
Белый255/255/255 в UI → уровни50/40/40. У Wujie в текущем MagicControl
подтверждён50/50/50. Пользовательские цвета OEM в общем случае используют
разные коэффициенты каналов R/G/B (в т.ч.5/6/6), плюс исключения палитры.
Порядок физических цветов пульсации1..4 GM6 отдельно не измерялся. Не выдавать
подписи/калибровку X5 за физически проверенную палитру GM6.

SingleZone хранит _AC_LightLevel/_DC_LightLevel и при Plugged/UnPlugged
применяет соответствующую яркость. GetBrightness возвращает сохранённый уровень,
а не прямое чтение0x78C. В нашем будущем getter нужен фактический EC readback.

5. Два разных времени

KeyboardCloseTimer — программный таймер бездействия OEM службы, события raw
keyboard/mouse заново запускают его. Истечение вызывает выключение, активность
возвращает подсветку/эффект. Это не найденный EC-регистр аппаратного таймаута.
В MagicControl уже есть общие checkbox/поле «Авто Выкл … сек»: использовать их
для этого смысла; не создавать ещё один вариант таймаута для GM6. В текущем
SettingsPage зафиксирован запрос владельца на EC timeout, сохраняющий действие
после выхода. Найденный программный OEM Timer этому требованию сам по себе
не соответствует: аппаратный timeout setter пока не раскрыт. Не включать
существующее поле с обещанием автономной работы только на основании Timer.
ManualInterval — другое время: задержка между цветами шестицветного цикла.
Не привязывать его к полю автоотключения. Новый контрол для него сейчас не нужен.
На Wujie и GM6 текущий UI таймаута отключён; Huawei допускает его по рабочему
OEM getter/setter. Наличие общего поля не доказывает подключённое исполнение.

6. Сопоставление с сохранённым EC-снимком GM6

build/audit-20261019/logs/dumps/dump-20261019-101104-0/ec.bin:
0x740=19;0x766=B4 (RGB bit2 установлен);0x767=00;
0x769/76A/76B=00/00/00;0x76C/76D/76E=00/32/32;
0x78C=02 (off);0x78E=EC (power support bit5 установлен);0x7C5=00.
Начальный цвет default0/50/50 совпадает с cyan/MonochromeIndex17 в OEM журнале.
Эти чтения принадлежат разным сохранённым моментам; это не текущий live-state.

7. Как подключать

Извлечь проверенную общую EC-механику подсветки из UI SettingsPage в один
переиспользуемый контроллер: getter, masked brightness/power/effect/color writes,
readback, откат собственных полей и общие OSD. Wujie и GM6 задают свои guards,
протокол и цветовую калибровку через профиль. Не копировать ещё одну SettingsPage.
GM6 допускается по точной SMBIOS/EC identity + RGB capability; при активном OEM
writer сохранять запрет конфликтующих записей. Никаких записей при создании
страницы, preview, дампе-read-only или получении Fn/Sc уведомления.
Реальное применение яркости/цвета/трёх эффектов затем требует readback и
визуальной проверки владельцем. Исследование само этих проверок не выполняло.

9. Последующее подключение по поручению владельца

После исследования владелец запросил подключить RGB и добавить шестицветный
цикл с таймером. Реализован общий core KeyboardBacklight/KeyboardColorCycle,
используемый Windows карточкой обеих MECHREVO и X5 ConfigurationRestore.
GM6 добавляет собственные identity/OEM guards через typed Gm6Controller.
Четвёртая кнопка «Цикл6» использует существующий ряд эффекта;6цветовых ячеек
и интервал1–3600с занимают существующий цветовой ряд, отдельный renderer не создан.
Цвет «Моно» сохраняется до старта цикла; выбранные6цветов/интервал сохраняются
в keyboard-cycle.ini. Процесс должен работать; startup-autoplay отсутствует.
Выход/новый эффект прекращают таймер без старого EC restore; внешнее изменение
RGB/эффектов тоже прекращает цикл. Fn-яркость не входит в ожидаемое владение.
Цветовая палитра штатных pulse-presets GM6 отключена до физической сверки
порядка; сам режим пульсации доступен с текущим/OEM начальным пресетом.
АвтоВыкл после выхода остаётся неподтверждённым; к полю не привязан fake timer.
Общий код компилируется в Linux, но RGB EC writer для этих плат там отсутствует.
Аппаратные пробы/GUI при подключении инструментами не запускались.
