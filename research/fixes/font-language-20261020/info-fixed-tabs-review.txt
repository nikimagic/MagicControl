ПОДТВЕРЖДЕНО ЧТЕНИЕМ

1. src/gui/common/TabLabels.h:9-16 содержит одинаковые шесть подписей UTF-8
   и Wide в том же порядке: FANs, SETs, KEYs, INFO, GPU Nvidia, GPU Radeon.
   INFO и регистр Nvidia соответствуют новому правилу владельца; модели не
   подставляют собственные названия и не выбирают отдельную реализацию вкладок.
2. src/gui/common/Layout.h:72-76 сохраняет enum Tab и индексы0..5, включая
   внутренний Tab::Bios=3; Windows использует общий Wide-массив и static_assert
   размера. Linux MainWindow.cpp:26 берёт UTF-8-массив из того же заголовка.
   pageNames{fans,sets,keys,bios,nvidia,radeon} остаются внутренними id.
3. Localization.h:232-238 защищает точные навигационные имена через
   isFixedTabLabel. render() вызывает protectedName до exact lookup (:327-328),
   поэтому каталог не переводит эти заголовки в существующем пути отрисовки.
4. Новый ключ Localization.h:28 имеет согласованные четыре значения:
   RU INFO · сведения о ноутбуке
   EN INFO · Laptop information
   SC INFO · 笔记本信息
   TW INFO · 筆記型電腦資訊
   Смысл точный; INFO сохраняется во всех локалях, описательная часть переведена.
5. BiosActions.h:3 задаёт один kInformationCaption. Windows BiosPage.cpp:137,
   :140 и Linux BiosPage.cpp:124 используют его для верхней информационной
   карточки; конкретные BIOS/UEFI/EC сведения ниже не переименовывались.
6. windows/main.cpp:50 сохраняет --tab=bios и добавляет --tab=info для того же
   Tab::Bios. Чтение параметра/порядок вкладок/команды устройств не изменены.
7. В просмотренном diff не менялись геометрия карточек, палитра, роли шрифтов,
   scroll mechanics/scrollbar, аппаратные методы, model guards или capabilities.
   Diff содержит только общий источник подписи, языковую защиту, заголовок
   информационной карточки и alias запуска. Runtime INI/JSON вне этого diff
