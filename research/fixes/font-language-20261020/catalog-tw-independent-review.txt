Независимая вычитка каталога EN / 繁體中文, 20.10.2026

Владелец production-каталога: агент Wujie. Этот агент не изменял каталог;
все исправления передавались владельцу, включая последнюю согласованную
с root замену SC/TW «и подтверждены» на «/подтверждены» для возврата PL.

Проверен окончательный freeze: 905 Entry, 3620 значений четырёх языков.
Все EN/TW строки вычитаны по смыслу относительно RU/SC. Статический разбор
сверил multiset имён placeholders в четырёх колонках, пустые значения,
дубли RU-ключей, остаточную кириллицу в переводных колонках и явные маркеры
упрощённых написаний в TW. Ошибок этих классов не найдено.
Точные SHA-256, число шаблонов и результат сверки с freeze владельца:
  catalog-tw-independent-review.json

Принятые уточнения:
— cyan RGB(0,255,255) = 青色 / Cyan, не light blue;
— мощность W = 耗電功率, не количество электроэнергии 耗電量;
— Honor resume_retained_high сообщает «remains off after resume» /
  «從睡眠喚醒後仍為關閉狀態», не новую команду выключения;
— «собственные изменения PL возвращены/подтверждены» сохраняет / во всех
  языках; не усиливает подтверждение исходного состояния до обещания записи;
— исправлены отмеченные EN-пробелы между словами и числами;
— разобраны typed semantic effect/mode/state и quantity total/free/limit/
  enforced/minimum/maximum/default: значения режимов переводятся, полные
  scalar+known-unit величины получают локализованные единицы; непрозрачные
  owner/path/model ID остаются данными, не предложениями для перевода.

Сохранены важные различия:
запрошено / сохранено / применено / подтверждено чтением;
readback / измеренный физический эффект;
потеря владения / подтверждённый возврат Auto;
неподтверждённый rollback / подтверждённое восстановление;
родной профиль батареи / неподтверждённый процентный порог;
монохромный Honor / аппаратная поддержка RGB;
снимок EC RAM / код прошивки.

Production-файлы Windows этого агента остаются замороженными. Последнее
разрешённое изменение DisplayFormat/FANs сохраняет прежний shortest формат
температуры через std::to_chars; локализуется только десятичный разделитель.

Это статическая лингвистическая/структурная проверка. Приложение, переводной
движок, тесты, GUI, EC и сборки не запускались. Не проверены визуальный fitting,
реальный font fallback/шейпинг и аппаратные эффекты. Неизвестные vendor
диагностики не объявляются переведёнными, если для них нет проверенного ключа.
