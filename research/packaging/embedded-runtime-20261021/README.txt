MagicControl 0.1.118 — зависимости внутри Windows EXE

28 ресурсов в каждом MagicControl.exe и mctl.exe: 15 обязательных PawnIO
runtime файлов,11 файлов двух пакетов Uniwill, оригинальный PawnIO2.2.0
установщик и notice. Все ресурсы сверяются с исходными байтами/размером/SHA256.
Содержимое модулей/SYS/INF/CAT не изменялось. Установщик совпадает с ранее
закреплённым SHA2561f519a22…; локально Authenticode Valid/namazso.eu.

Один EmbeddedRuntimeWindows обслуживает все3 загрузчика и explicit installer.
Нужная группа извлекается в %ProgramData%/MagicControlRuntime/<bundleSHA256>/.
Защищённые каталоги Administrators/SYSTEM; проверка owner/ACL, запрет reparse,
атомарная публикация, сверка и read-only pin файлов до конца процесса.
Обычный LoadLibraryEx использует именно эту библиотеку. EC/службы/драйверы
не открываются механизмом извлечения. INFO сохраняет интерактивный мастер
и проверку Authenticode, файл установщика не скачивается заново.

Диагностика читает ресурсы и их хэши без извлечения. Stager удаляет только26
известных прежних loose файлов и проверенно пустые директории; пользовательские
неизвестные файлы не стирает. Папок drivers/PawnIO в рабочей Windows portable нет.
Лицензии/notices доступны в licenses/PawnIO. Упаковщик адаптирован, не запускался.

verify-delivery.py проверяет450+ актуальных входов общего билда, четыре бинарника,
56 ресурсов PE,29 исходных runtime файлов,6 личных файлов,15 protected UI файлов
и11 архивных файлов. Тесты, GUI, загрузчик кэша и аппаратные функции не запускались.
Практическая загрузка модулей в работающем приложении требует проверки пользователем.
