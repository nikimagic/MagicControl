MagicControl 0.1.114 — отдельные плотные строки текущих показаний

После уточнения пользователя общая строка показаний удалена. В EC слева
и Windows/OS справа используются шесть пар «подпись — значение»:
заряд батареи; зарядка/разряд; циклы; температура; напряжение; ток.
Каждое поле имеет собственную строку высотой bodyMetrics без rowGap.
Направление мощности указано словами и красным/зелёным цветом.

Общий placeBatteryTableRows используется и для текущих показаний, и для
остальных батарейных таблиц. Убрано экспериментальное расширение MetricLine;
CPU/GPU summary остались с прежним алгоритмом. Подписи RU/EN/SC/TW,
короткие основные подписи и единицы Wh из113 сохранены.

Аппаратные источники, команды, логи, шрифты и scrollbar не менялись.
verify-delivery.py проверяет фактическую общую версию,450 входов сборки,
четыре бинарника portable,6 личных файлов,9 защищённых файлов UI и11 файлов
архива разряда. Тесты, GUI и аппаратная проверка не запускались.
