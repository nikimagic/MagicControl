MagicControl0.1.106 — отдельный журнал батареи для всех профилей

BatteryLog=1 в app-settings.ini включает battery.jsonl и подробную карточку SETs.
BatteryLog=0 отключает подробный сбор и скрывает только диагностический блок.
AllLogs независим; отсутствие BatteryLog в старом конфиге означает1.
После ручного изменения конфига следует перезапустить программу.

Общий LogSink пишет UTC/session/elapsed/seq один раз и зеркалит ключевые строки.
В battery.jsonl — полные battery/battery_candidates/battery_power и события ОС;
в общем журнале — SOC/flow/flags/пороговые действия и сводка питания без raw таблиц.
Один аппаратный poll для обоих файлов, общий mutex защищает snapshot/rotation.
Фиксированный battery.jsonl дописывается между запусками; сохраняются3 предыдущих
сегмента по8MiB. При копировании дампа включается отдельный battery.jsonl.

Windows flags/питание/политика/разрешённые EC поля регистрируются при изменениях
и при каждом наблюдённом проценте независимо от burst60 CPU/GPU. Скрытая FANs
поддерживает штатный1Hz сбор с BatteryLog=1. Linux сохраняет доступные sysfs
статусы/пороги/флаги без обрыва при скрытии вкладки. Запись не захватывает
события во сне/выключенной программе, пропущенные проценты не синтезируются.

Основная карточка батареи обеих ОС всегда содержит три оценки времени по EC:
до разряда, до100% и до верхнего порога. Используется прежняя общая формула
ёмкость/ток, не новый firmware sensor. Без подтверждённого EC reader — прочерк,
без подстановки ОС под EC. Диагностическая карточка остаётся при BatteryLog=1.

Механизм общий для Wujie, GM6, HYDROC, Honor и Unknown, но аппаратные карты
не переносятся между моделями. Порог97 и команды EC/UEFI/SMBus не изменялись.
490.3 переименован в нейтральный BATTERY_STATUS_BIT3? после наблюдения
установленного бита и при разряде. Стиль остальных карточек, шрифты и scrollbar
не менялись. Оценки/подписи общие RU/EN/SC/TW.
