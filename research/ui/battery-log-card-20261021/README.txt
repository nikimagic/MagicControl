MagicControl 0.1.111 — компактная батарея и раздельные подробные карточки

Основные EC/Windows блоки уплотнены: заголовок32DIP, сводка58DIP (стандартная
высота monitor tile), промежуток6DIP, информационные строки минимум22DIP по
bodyMetrics. Подписи и значения идут рядом на одной строке, цвета времени
сохранены. Лимит CPU/EPP подписаны компактно для RU/EN/SC/TW.

Из диагностической карточки удалены смешанная сводка «Текущие показания»
и её заголовок/геометрия. Подробные сведения разделены на две самостоятельные
карточки: EC слева (103 поля), Windows/OS справа (27 полей). Заголовки,
статусы и высоты независимы; EC snapshot status не показывается над Windows.
Повторяющийся третий столбец источника убран: источник задаётся карточкой.
Строка об отсутствующем PawnIO provider не подменяется EC/Windows данными.

Одна placeBatteryTableRows для основных и подробных таблиц обеих ОС;
ширины значений измеряются native шрифтом. Подробные длинные подписи/значения
допускают перенос, а основная таблица остаётся компактной. Source partition
общий и не меняет значения/датчики/журналы. Диагностические карточки сохраняют
BatteryLog gate. Шрифты, палитра, остальные карточки и scrollbar mechanics
сохранены. Новых аппаратных обращений или записей нет.

Проверка поставки: verification JSON после завершения общего Release0.1.111.
Обе реальные portable,450 исходных входов,4 GUI/CLI бинарника,9 защищённых
UI/палитра sources,6 личных файлов,11 архивных логов. Тесты,GUI и аппаратные
пробы не запускались; только компиляция и статическая сверка файлов.
