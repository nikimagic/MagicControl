MagicControl 0.1.119 — подсветка первой, сообщения EC в подвале

Общий порядок SETs: подсветка; батарея с диагностикой; CPU/APU. Логические
индексы сохранены, весь блок подсветки перенесён вместе с контролами.

Общий FooterStatuses получает исходные статусы FANs/SETs/KEYs. Подвал показывает
сообщение активной страницы, при отсутствии — последнее сообщение. Счётчик
опросов/подпись секундного обновления больше не выводятся. Дублирующие строки
SETs/FANs убраны; версия и потребление справа сохранены. Windows PostMessage
и GTK GMainContext/weak widget выполняют событийную перерисовку без новых
таймеров и чтений EC. Повтор одинакового сообщения не создаёт repaint-loop.
Preview обозначается явно, при смене профиля сообщения очищаются. Слова
«сохранено», «не подтверждено», ошибки/результаты не переписываются в success.

verify-delivery.py сверяет актуальные application inputs, четыре бинарника,
56 PE ресурсов,29 runtime исходников,6 личных файлов,8 protected UI файлов
и11 архивных файлов. Внешних drivers/PawnIO нет, архивы118 не менялись.
Тесты, GUI и аппаратные операции не запускались. Внешний вид требует просмотра
в штатном приложении пользователем.
