Основная карточка батареи: ёмкости по источникам и политикаWindows

Добавлены общие строки: полная/проектная ёмкость и здоровьеОС,
полная/заводская ёмкость и отношениеfull/designEC, имя базовой схемыWindows,
настроенный предел частотыCPU иEPP отдельноAC/DC. Вместе с прежними тремя
оценками времениEC основная карточка содержит10 строк. BatteryLog не влияет
на эти строки; подробный диагностический блок по-прежнему зависит от него.

Числа не зашиты: Windows Battery Class/sysfs и разрешённый EC reader.
Native единицыmWh/mAh/relative не смешиваются. EC здоровье показывается
с точностью3 знака; Windows—1 знак. Unknown не подменяется другими источниками.

Typed BatteryPowerPolicy читает активную базовую схему через PowrProf,
общая Windows функция обслуживает карточку и диагностическийJSON.
Это read-only настройки, не фактическая частотаCPU, неSMU лимит и неhardwareEPP.
Читаются default processor settings, неoverlay/QoS/efficiency-class1 override.
ОшибкиAPI отображаются прочерками, а ненулём. EPP валидируется0..100.
В Linux Windows policy отсутствует, Windows-значения не придумываются.

Все модели/обе ОС используют один primaryBatteryDetails иsetsGeometry.
Источник указан у каждой строки, подписиRU/EN/SC/TW. Контролы/шрифты/цвета
и scrollbar mechanics сохранены; выросла только батарейная карточка.
Обработчик перерисовки охватывает все10 строк после принятия sample.
Никаких setters политикиWindows,EC/SMU/UEFI или изменений порога97.
