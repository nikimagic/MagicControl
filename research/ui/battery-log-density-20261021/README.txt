MagicControl 0.1.112 — максимально плотные подробные карточки батареи

Диагностические строки EC/Windows теперь имеют ровно высоту текущего
body-шрифта. Дополнительных межстрочных промежутков нет (rowGap=0).
Убран запас под вторую строку: подписи/значения однострочные, длинный текст
имеет штатное многоточие. Шрифт не уменьшен, содержимое параметров и файлы
логов не сокращаются. Карточки EC слева иWindows справа сохраняются.

Верхний отступ заголовка6DIP; статус занимает одну текстовую строку;
параметры начинаются через2DIP после него. Footer уменьшен до размера текста.
Shared placeBatteryTableRows явно принимает gap:0 для подробностей,
прежние4DIP для primary. Основные карточки и их геометрия не изменились
по смыслу: смещение теперь передаётся в пикселях, а не повторно масштабируется.

Один layout обеим ОС/всем профилям. Шрифты, палитра, кнопки, источники,
формулы/датчики, журнал и scrollbar mechanics прежние. Данные не менялись,
аппаратные команды не добавлены. См. verification JSON по завершении поставки.
Проверки — компиляция и статические версии/хэши; GUI/тесты/железо не запускались.
