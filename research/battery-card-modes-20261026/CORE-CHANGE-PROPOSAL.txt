Предлагаемые изменения ядра для двух вариантов карточки. 26.10.2026
Исторический план. После его явного одобрения владелец изменил решение:
нижний порог в ядре и автосохранение НЕ УДАЛЯТЬ. Пункты1/2 ниже отменены.
Setter/rollback/restore/CLI и прежние модельные ограничения восстановлены;
скрыт только UI редактор. Проверка: LOWER-CORE-RESTORED.json, эталон70897c7.
Штатный WUJIE writer одобрен отдельно в составе этого плана.
Дополнительное расширение CLI для WUJIE и общая смена restore-предиката
отклонены автоматической проверкой и исключены из итоговых изменений.

1. Удалить запись неизвестного 7D0 из WUJIE percentage path и его rollback.
   Верхний предел/WMI storage/существующие наши политики сохранить.
   Фактически прочитанный 7D0 оставить только сырым наблюдением, без изменения.
2. Аналогично убрать запись restart из NativeBatteryController percentage path,
   явного setChargeRestart и автоматического восстановления старого ChargeRestart.
   Старые пользовательские файлы не удалять; их нижний параметр больше не применять.
3. В штатном режиме менять только 7A6.mask30, код0/1/2. Fresh masked RMW,
   readback и ограниченный rollback только нашей маски. Все соседние биты сохранять.
4. Подключить этот механизм к точному WUJIE82/72/26, отдельно от уже работающего
   WUJIE процентного контроллера. Остальные платы сохраняют собственные guards.
5. Штатный writer не записывает 7C3,770,ROM tail,FLASH,742,нижний порог,FAN/APU.
   Никакой универсальной подстановки7/FF или восстановления якобы заводского ID.
   При неподтверждённом/нашим образом изменённом контексте — отказ до записи.
   Если741.0 отсутствует, не поднимать его произвольной записью ради кнопки.
6. Меню только переключает представление. EC-команда — лишь по явному нажатию
   штатной кнопки либо восстановлению прежде подтверждённого и сохранённого выбора.
   Новое отсутствие выбора не порождает startup writes.
7. Обычный процентный путь не получает записи напряжения/идентичности из этой
   UI-перестановки. Наши4/FF,7/04,7/FF остаются отдельными явными командами APU.
8. Сохранить actor/action/version/time/request/result/readback в общем журнале;
   неизвестные исходные ID не объявлять заводскими.

Никакие аппаратные команды помощником запускаться не будут.
После внесения: сборки Windows/Linux, обновление portable и локальный коммит.
Принудительное завершение MagicControl и публикация GitHub не предусмотрены.
