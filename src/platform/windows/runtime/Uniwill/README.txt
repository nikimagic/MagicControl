Uniwill OEM ACPI Driver — Windows x64
Версия INF: 10.48.11.331, дата DriverVer: 2025-10-28.
Аппаратный идентификатор: ACPI\INOU0000.

Состав: UWACPIDriver.sys, UWACPIDriver.inf, UWACPIDriver.cat.
Файлы скопированы без изменений из установленного пакета DriverStore.
Это сторонний OEM-компонент; лицензия NikiMagic на MagicControl на него
не распространяется. Права принадлежат соответствующим правообладателям.

СТАТУС ПРАВ НА РАСПРОСТРАНЕНИЕ
Отдельное разрешение на перепаковку и публичное распространение этого драйвера
не найдено. Наличие файлов в локально подготовленном архиве не подтверждает
такое разрешение. Перед публичной публикацией требуется определить применимые
условия OEM/Uniwill и получить право распространения этого пакета.
Подпись Microsoft подтверждает проверку пакета, а не право его перепаковки.

УСТАНОВКА
Если совместимый драйвер уже установлен, повторная установка не требуется.
Программа автоматически этот пакет не устанавливает.
На совместимом компьютере установку можно выполнить вручную из повышенного
терминала, находясь в корне portable-папки:

pnputil /add-driver ".\drivers\Uniwill\UWACPIDriver.inf" /install

Не изменяйте SYS/INF/CAT: изменение нарушит проверку подписи пакета.
Установка драйвера не означает поддержку конкретной платы MagicControl.

ВЫБОР ПАКЕТА
Этот комплект10.48.11.331 сверён с полным родным пакетом GM6 и DriverStore
нашего Wujie. Родной HYDROC11.2.18.347 находится отдельно в11.2.18.347.
Выбирать по точной модели/проверенной версии, не сравнивать номера разных OEM
как универсальную шкалу обновлений и не устанавливать два комплекта подряд.
SYS/INF/CAT должны всегда принадлежать одному комплекту.
