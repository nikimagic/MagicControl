Uniwill OEM ACPI Driver11.2.18.347, Windows x64
Версия INF11.2.18.347 от27.08.2024. ProviderUniwill, ACPI\INOU0000.
Источники владельца: ControlCenter5.23.51.56 Eluktronics V4 и
XY14PTL ControlCenter5.57.1.2 MECHREVO GX (CustomizeTarget57).
Полные тройки SYS/INF/CAT двух OEM-пакетов побайтово совпадают.
SYS/INF/CAT сохранены побайтово, подписи не изменены. Хэши — PROVENANCE.json.

Этот комплект выбран для точной Eluktronics HYDROC-16 G2 / HYDROC-16.
Пакет10.48.11.331 для Wujie/GM6 находится в родительской папке и не подменяет
этот комплект. Не смешивать SYS/INF/CAT из разных версий; одинаковый hardwareID
и имя службы не являются доказательством совместимости с другой платой.

Если драйвер уже установлен и совпадает с проверяемым HYDROC SHA, установка
повторно не требуется. Программа не устанавливает/не заменяет его при запуске.
Для явной ручной установки только этого пакета в повышенном терминале,
находясь в корне portable:
pnputil /add-driver ".\drivers\Uniwill\11.2.18.347\UWACPIDriver.inf" /install

Установка пакета не включает неподтверждённые FANs/RGB/MUX функции.
MagicControl отдельно проверяет точную модель и хэш установленного SYS.
Права на OEM-компонент принадлежат его правообладателям. Отдельное разрешение
на публичное распространение не установлено; лицензия MagicControl на эти
сторонние файлы не распространяется. Точные сведения — PROVENANCE.json.

Наличие той же тройки в пакете MECHREVO GX — подтверждение происхождения,
но не доказательство совместимости карты EC XY14PTL с X5SP4NAG/GM6.
