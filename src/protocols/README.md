# Протоколы

Здесь описывается смысл команд, регистров и форматов данных, независимо от того,
какой OS-драйвер доставляет запрос. Сейчас подтверждён только uniwill/x5sp4nag.
Не превращать карту этой платы в общую карту всех Uniwill, ASUS или Lenovo.
Алгоритмы с прямыми Windows API находятся в соответствующем профиле устройства.
