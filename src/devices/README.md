# Устройства

Папки: производитель → точная плата SMBIOS → профиль и особенности управления.
Реестр DeviceRegistry выбирает профиль; общие протоколы и OS-драйверы не копируются
в каждую модель. Каталог содержит X5SP4NAG с подтверждённым Windows-управлением
и 11 плат из пользовательских отчётов без аппаратного допуска.

HUAWEI HLYL-WXX9 добавлен отдельно: typed OEM WMI/sysfs, а не raw EC backend.
Пороги зарядки, Fn Lock и Windows Turbo включаются только по корректным getter.
Проверены подсветка, PWM, зарядка и SMU на HLYL BIOS1.09; границы и результаты
см. huawei/hlyl-wxx9/README.md и research/devices/hlyl-wxx9/.

Правила расширения и карта перенесённых файлов: docs/DEVICE-ARCHITECTURE.md.
Новый профиль нужно явно добавить в CMakeLists.txt и реестр производителя.
Не включать возможности на основании только установленного OEM-драйвера.
