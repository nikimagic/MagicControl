# SETs: подсветка клавиатуры, эталонный код и пределы эффектов

Источник эталона: декомпиляция `Decompiled/DefaultTool` из родного MECHREVO
Control Center. Текущий экран SETs показывает «Моно», «Пульсация» и «Мульти».

## Какой путь выбирает родной код

`LightingModel/LM_EC_RGB.cs` читает регистр EC **1894 (`0x766`)**. Если установлен
бит `0x04`, а project ID не распознан как отдельная монохромная клавиатура,
служба выбирает `RGBKB_Type.SingleZone` и класс
`MyControlCenter.MyRgbKeyboard/SingleZone.cs`. В снимках платы
`WUJIE Series-X5SP4NAG`: project ID `0x740 = 26`, `0x766 = 0x94`. ID 26 нет в
списке монохромных project ID родной службы; `0xD00 = 0x25` также имеет bit 0,
который эталон проверяет как поддержку SingleZone. MagicControl проверяет тот
же `0x766/0x04`. Это подтверждает SingleZone-путь для данной платы.

`SingleZone.Translate_EC_EffectIndex` сопоставляет четыре эффекта:

| Эффект | EC-код | Действие эталона |
|---|---:|---|
| Single / Моно | 1 | Остановить Rainbow, Manual и Breathing, записать цвет |
| Breathing / Пульсация | 2 | Остановить Rainbow и Manual, записать индекс дыхания в EC |
| Rainbow / Мульти | 5 | Остановить Manual и Breathing, включить Rainbow |
| Manual | 64 | Остановить Rainbow и Breathing, переключать ручные цвета |

`Wave` есть в общем перечислении `RGBKB_Effect`, но SingleZone его не
сопоставляет. В `SetColorMode` неизвестный код попадает в fallback: остальные
режимы выключаются и остаётся статический цвет. Отдельный HID/ITE путь
поддерживает `Wave` (код эффекта 3) и `ColorfulWave` (52), однако это другой тип
клавиатуры. Его команды нельзя автоматически переносить в EC SingleZone.

## Что означает индекс пульсации

Родной SingleZone вызывает `StartBreathingMode(BreathingColorIndex)`, читает EC
**`0x7C5`**, очищает младшие три бита и записывает индекс 1–4; ноль выключает
Breathing. `SetEffect` сохраняет этот параметр как `BreathingIndex`, а сам
метод называет его `BreathingColorIndex`. Дефолт — индекс 1. В записанном
эталонном действии выбран индекс 1 и красный цвет. Это индекс эффекта/цвета,
а не миллисекунды.

`ManualInterval` отдельно задаёт задержку ручной смены цвета: эталон умножает
его на 1000 и устанавливает `Timer.Interval`. Значение по умолчанию 10 — это
10 секунд между цветами режима Manual; таймер не участвует в Breathing.

У HID/ITE-реализации есть отдельный байт `save_speed`, который передаётся
вместе с эффектом. Эталон кодирует его так: значения интерфейса `0, 1, 2, 3, 4`
переходят в байты `10, 7, 5, 3, 1`. Это дискретный код скорости для ITE-команды;
исходник не задаёт длительность цикла пульсации в миллисекундах, и эта таблица
не относится к SingleZone EC-пути.

## Сопоставление с текущим экраном

MagicControl записывает:

- **Моно:** сбрасывает индекс `0x7C5` и Rainbow bit `0x80` в `0x767`.
- **Пульсация:** ставит индекс 1 в младшие биты `0x7C5`, сбрасывает Rainbow.
- **Мульти:** ставит bit `0x80` в `0x767`, сбрасывает пульсацию.
- Цвет: EC `0x769–0x76B`; яркость: EC `0x78C`.

Значит, текущая «Пульсация» соответствует родному Breathing index 1. В найденном
коде SingleZone нет регулировки её скорости или времени полного цикла. Нельзя
использовать младшие биты `0x7C5` как «медленно/быстро»: они задают индекс
пульсации. Wave доступна в общем ITE-интерфейсе, но не в выбранном для этой
конфигурации SingleZone-пути. Я не добавлял неподтверждённые команды и не менял
экран SETs.

Ключевые исходники:

- `Decompiled/DefaultTool/LightingModel/LM_EC_RGB.cs` — выбор SingleZone по
  `0x766/0x04`.
- `Decompiled/DefaultTool/MyControlCenter.MyRgbKeyboard/SingleZone.cs` — коды
  Mono/Pulse/Rainbow, индекс Breathing и таймер Manual.
- `Decompiled/DefaultTool/LightingModel/LM_ITE_RGB.cs` — отдельный Wave и speed
  mapping для ITE.
- `src/gui/windows/SettingsPage.cpp` и `src/core/include/MagicControl/EcRegister.h`
  — чтение/запись текущих команд SETs.
