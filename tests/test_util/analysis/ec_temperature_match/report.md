# Поиск температур памяти и диска в прошивке EC

Метод: каждый байт EC имеет собственное время съёмки, поэтому многосекундный снимок не считается мгновенным. Опорный канал интерполируется на время каждого байта, затем считается корреляция по кадрам. Совпадение по диапазону без совпадения по времени датчиком не считается.
