## Выводы

- CPU UI использовал ADL PMLog `TEMPERATURE_CPU`, слот 32. Во всех 110 снимках этот
  показатель ниже прочитанного через SMN Tctl/Tdie: на 1,5–6,875 °C,
  в среднем 2,809 °C. Это различие источников; форматирование UI не вычитало градусы.
  Постоянную поправку прибавлять нельзя: разница меняется при нагрузке.
- Например, `2026-10-12T07:36:29.6Z`, снимок 1: ADL CPU 50 °C,
  SMN `0x69EB0000` → 56,875 °C, EC 56 °C. Новый UI показывает 56,9 °C.
- GPU использовал PMLog GFX, слот 28; Edge (8) на этой конфигурации не поддерживается.
  Средняя разность ADLX−GFX = −0,1 °C. В 109 из 110 снимков расхождение ≤1 °C.
  Один снимок дал GFX 56 °C против ADLX 52 °C, то есть GFX был выше.
  Систематическое занижение GPU не подтверждено.
- GPU Hotspot и Edge в записанных снимках не поддерживаются. Их нельзя выдавать
  за измеренную температуру или заменять выдуманной поправкой.
- EC `0x43E` — отдельный показатель CPU для термоуправления; не используется как
  температура GPU. Слоты SoC и CPU не переставлены.

## Исправление

Основная CPU-температура теперь PawnIO / SMN 0x59800, подпись `PawnIO · Tctl/Tdie`.
Чтение разрешено только на подтверждённой плате, использует штатный подписанный
AMDFamily17.bin и общий PCI mutex. При ошибке/занятости PCI используется свежий ADL
с подписью `AMD ADL · CPU`, старый SMN-снимок не переносится. В журнале сохраняются
выбранный источник и оба показания CPU. GPU остаётся GFX с явной подписью.

Декодирование: `(raw >> 21) × 0.125`, −49 °C при аппаратном флаге диапазона
или TJ-select; это формат регистра, не калибровочная поправка. Сверено с
[исходником Linux k10temp](https://github.com/torvalds/linux/blob/master/drivers/hwmon/k10temp.c).
Модельные смещения не угадываются; Tctl и Tdie могут отличаться на других моделях,
как описано в [документации k10temp](https://docs.kernel.org/hwmon/k10temp.html).
Значения PMLog и их идентификаторы сверены с
[официальным ADL SDK](https://gpuopen-librariesandsdks.github.io/adl/adl__defines_8h.html).

Карточка и маркер графика берут одно `processors[channel].celsius`.
Карточка округляет до 0,1 °C; положение точки и подпись «Факт» используют исходное
число. Например, 39,625 °C на графике и 39,6 °C в карточке — одно показание.
Программный контроллер кривых получает те же источники независимым свежим чтением.
Следствие: при CPU Tctl выше прежнего ADL контроллер может раньше выбрать следующую
ступень той же сохранённой кривой. Профили и точки кривых не менялись.

## Проверка UI

`review_temperatures.py` извлекает из исходных JSONL сырые SMN, ADL и ADLX значения,
времена, ожидаемый текст. `magiccontrol_tests --temperatures` воспроизводит их через
рабочие `decodeZenTctl`, `applyZenCpuTemperature`, `processorCard` и форматирование UI.
В Windows и Linux: 110 снимков, 671 проверка, 0 ошибок. Текст двух файлов
`ui-replay-*.tsv` совпадает (различается только системное окончание строк).
Проверены недействительные регистры, оба аппаратных флага диапазона и резерв ADL.
Аппаратное применение кривых этой проверкой не запускалось. Анализ ACPI, всех
числовых форматов EC и выводы о GPU/SoC/NPU — в
[`firmware_temperatures/report.md`](../firmware_temperatures/report.md).

Обновлённый Windows EXE запущен; его реальное окно осмотрено через computer-use:
CPU 39,6 °C / PawnIO Tctl/Tdie, GPU 38 °C / AMD ADL GFX. «Факт» CPU 39,625 °C.
В свежем журнале также получены CPU 41,125 °C против ADL 39 °C и CPU 40 °C против ADL
38 °C. Подтверждено, что подписанный PawnIO-модуль возвращает SMN в самой программе.
Фрагмент журнала сохранён в `live-ui-telemetry.txt`. Linux проверен сборкой и
воспроизведением логов; аппаратных температур в чистом WSL нет.

Повторение проверки из корня проекта:

```text
python tests/test_util/analysis/review_temperatures.py
build/windows/bin/Release/magiccontrol_tests.exe --temperatures tests/test_util/analysis/temperature_review/samples.tsv tests/test_util/analysis/temperature_review/ui-replay-windows.tsv
build/linux/bin/magiccontrol_tests --temperatures tests/test_util/analysis/temperature_review/samples.tsv tests/test_util/analysis/temperature_review/ui-replay-linux.tsv
```
