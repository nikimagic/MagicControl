# EC при батарее ниже 10%: батарея / зарядка 65 Вт

Дата: 17.10.2026. Сбор только чтением SensorProbe, настройки не записывались.
Это окно данных/регистров EC 0x000–0xFFF, не исполняемый образ прошивки.

- Батарея: 8%, четыре снимка по 4096 байт; ошибок 0.
- Сеть: блок 65 Вт по сообщению пользователя, Windows PowerOnline=true и Charging=true, 8%; два снимка по 4096 байт; ошибок 0.
- Все исходные technical.json/dump.jsonl сохранены; EC каждого кадра дополнительно экспортирован в ec-sample-N.bin.

В 171 адресе различаются наборы наблюдавшихся значений; в 84 из них значение стабильно внутри каждой серии и различается между сериями. Это не доказательство причинной связи: присутствуют динамические датчики и служебные поля. Детали в comparison.json.

В 0xF00–0xF5F различий нет. PWM и обороты менялись в процессе штатной работы.

Вывод: подключение 65 Вт распознано Windows и EC (0x7CE=65), зарядка идёт. Платформа, порог зарядки и override лимитов APU сохранились. Эти снимки при экономичном лимите 15/10/10 не проверяют максимально допустимую мощность при низком заряде и не доказывают отсутствие дополнительного ограничителя. Фактические лимиты SMU нельзя подменять EC override-значениями.
