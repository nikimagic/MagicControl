# FANs и SETs: восстановление по состоянию EC

## События проверки и восстановления

Автоматическое сравнение настроек и восстановление разрешены только при запуске
программы и после подтверждённого сна/гибернации (уведомление Windows либо часы
elapsed/unbiased). Показ вкладки, сворачивание, разворачивание, трей, обычное
включение экрана и изменение AC/DC не запускают восстановление.

Таблицы FANs читаются интерфейсом один раз при создании страницы на запуске.
Фоновое чтение таблиц каждые пять опросов удалено. После пользовательской команды
интерфейс получает состояние из ядра. Мониторинг датчиков и выполнение выбранной
кривой продолжаются; подтверждение явных пользовательских записей сохраняется.
Индикация адаптера выполняется отдельно, без сравнения/восстановления FANs/SETs.

## FANs (Windows)

- Default: прошивка EC, RAM-управление и Fan Boost выключены.
- Manual и Min: один протокол RAM-управления, разные сохранённые кривые.
- Max: аппаратный Fan Boost (`0x751 & 0x40`), график 100% иллюстрирует режим.
- Владение RAM-управлением: `0x7C6 & 0x04`. Аппаратное разделение каналов:
  `0x7C5 & 0x80`. Программная связь CPU=GPU сохраняет раздельный аппаратный
  доступ для RAM-кривых и задаёт одинаковый выход по большей температуре.
- После пробуждения совпавшие флаги не вызывают повторного применения FANs.
  Расхождение восстанавливает выбранный режим вентиляторов, без переустановки
  производительности, подсветки или устройств Windows.
- RPM/PWM — только телеметрия. Нулевые, запаздывающие и недоступные показания
  не определяют владение и не отменяют выбранный режим.
- При запуске новая сессия должна получить собственное владение ручным режимом;
  совпадение флагов само по себе не передаёт ей таблицы другой сессии.

Проверка идентичности платы, исключительное владение, подтверждение записей,
контроль свежести температур и температурная защита сохранены.

## SETs (Windows)

Сохранённые поля сравниваются с доступным чтением EC/Windows. Применяются только
расхождения; неизвестное значение не считается сбросом. Совпавшая подсветка
не инициализируется заново при каждом уведомлении о пробуждении.

Изменение подключения адаптера не является событием сна. Оно даёт временную
индикацию клавиатурой: зелёный при подключении, красный при отключении, одна
секунда после применения цвета, затем возврат сохранённого эффекта/RGB/яркости.
EC-уровни цвета 0..50. Временный цвет не сохраняется в конфигурации.
Начальное состояние и уведомления первых пяти секунд после пробуждения не
дают вспышку. Последующее изменение заменяет ожидающую индикацию.

## Проверка

Windows GUI и CLI собраны. Физические сценарии гибернации, подключения адаптера
и возврата эффектов требуют проверки на ноутбуке. Автоматические тесты не
запускались. Linux-управление EC этой правкой не добавляется.
