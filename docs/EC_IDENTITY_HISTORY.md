# Идентификаторы EC: наблюдение до автоприменения

INFO использует общий снимок: Project ID `740`, платформа `7C3` и все 16 байт
`770–77F`. Project ID не является платформой, ROM ID или GUID прошивки UEFI.
HEX и десятичное число показывают фактически прочитанный байт, включая 00/FF.
Непрочитанное отображается как `??`; значение профиля или реестра не подставляется.

GUI и CLI вызывают `recordStartupRomId` до создания контроллеров и восстановления
настроек. Проверенный read-only транспорт читает Project ID перед платформой/ROM.
Запись `startup_read`, origin `startup`, reason `before_automatic_apply` сохраняет
версию приложения, локальное/UTC-время, реальную плату, источник и результат.
Это состояние до автоприменения именно этого запуска. Оно не доказывает, что
раньше никогда не работало другое ПО или что байты имеют заводские значения.

Файлы `project_id`, `platform_id`, `rom_id` находятся в `logs_<плата>`.
Общий append-only механизм блокирует файл и дописывает строку, не обрезая и
не ротируя историю. Существующие стабильные чтения 740 фиксируют изменение/
восстановление наблюдения без дополнительного таймера. Во всех строках истории
есть `project_last_observed` и `project_read_at`: сохранённое наблюдение не
выдаётся за одновременное чтение при последующей смене политики.

«Обновить сведения» собирает новый снимок, пишет его в историю и штатный журнал,
а `bios-inventory.json` сохраняет project в metadata schema2. Старые schema1
сохраняют реальные platform/ROM, но не получают выдуманный Project ID. При сбое
чтения INFO сохраняет предыдущий успешный снимок с его временем; свежая ошибка
и частичные данные отдельно отражены в журнале. Общая геометрия INFO не меняется.

Поддержка reader не расширяется этим журналом. При неизвестной модели,
`--no-ec`, неподходящем драйвере или недоступном Linux-транспорте сохраняется
явный отказ/неизвестное значение. Драйвер не устанавливается и не запускается,
EC-записи и настройки не применяются ради идентификации.

Первые присланные INFO-отчёты GM6 (18.10.2026 12:57:49) и WUJIE
(20.10.2026 20:05:17) этих полей не содержали. Исходные 740/7C3/770 по ним
неизвестны. Поздний RAM-дамп и статический BIOS writer — отдельные доказательства.
