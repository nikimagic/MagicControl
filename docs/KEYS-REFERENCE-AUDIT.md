## Общий флаг приложения

В эталоне `EcApplicationPresence` действует на протяжении работы приложения.
В MagicControl ранее Default и Max сбрасывали `0x741.0`, тогда как Manual
устанавливал его. Это совпало с пользовательским наблюдением: Sc и постоянная
подсветка работали в Manual, но терялись в Default/Max.

Теперь запрос присутствия выполняется на том же рабочем потоке, который
управляет вентиляторами, при запуске и восстановлении питания. Default/Max
сохраняют `.0=1`; ожидаемое состояние контроллера обновляется согласованно.
Если обнаружена оставленная RAM-таблица с `.0=0`, она не активируется ради
подсветки: её должен восстанавливать владелец таблицы. При завершении снимается
присутствие только при отключённой RAM-таблице.

Клавиатурное пробуждение также перенесено на весь срок работы приложения:
Raw Input передаёт факт активности без хранения клавиш, мышь его не запускает.
После паузы выдерживаются 75 мс, затем применяется текущая яркость стробом
`0x78C.4`. Явный Off сохраняется; события Fn-яркости не воспроизводятся в EC.
