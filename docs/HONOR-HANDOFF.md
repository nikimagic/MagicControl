## Исторические заметки

Цель пользователя: исправить 100% заряд, довести вентиляторы, подсветку и лимиты.
Прочитать AGENTS.md и src/devices/huawei/hlyl-wxx9/README.md. Исходники приватны;
GitHub nikimagic/MagicControl содержит только документацию и бинарные релизы.

Текущий локальный коммит66c837f, опубликованы Windows0.1.16/Linux0.1.17.
После него есть НЕЗАКОММИЧЕННЫЕ правки. Windows0.1.19 и Linux0.1.20 собраны.
Сначала сверить hostname и SMBIOS — предыдущая работа шла на MECHREVO.

1. Запустить Tools/Collect-HonorDiagnostics.ps1 на настоящем Honor (только чтение).
2. Исследовать штатные DSDT+все SSDT, WMAA dispatch GLIV/SLIV и fan SFNM/SFND.
   Не переносить команды FLMH-XX/FRI-H76. В сети HLYL DSDT изменена Hackintosh,
   не равна BIOS1.09. FanMode getter0C04 есть в сборщике, setters не разрешены.
3. 100% уже изменён на95/100 (вместо0/100), добавлены bounded readback/rollback.
4. Явная запись мощности реализована в ApuPowerReader::applyHlylLimits через
   Renoir MP1, не PSMU; нужна аппаратная проверка, исходное состояние сохранять.
5. Таймаут подсветки1206/1106 включается по getter; новая яркость131406 запрещена
   дляHLYL до доказательства штатным dispatcher. Linux — лишь доступные OEM sysfs.
6. Никаких автозаписей/постоянных таймеров enforcement. Не запускать на чужой плате.

Логи пользователя logs.zip и logs(2).zip показывают fn/turbo readback, пороги
90/95 и80/85; две попытки0/100 дали40/70. Аппаратная остановка заряда ещё не доказана.
Прежние пользовательские изменения INI/tests EXE/research не включать в коммит
вслепую. Авто-публикация релиза в текущем этапе не запрошена.
