# EC_manual: опыт автономных температурных таблиц

Windows FANs: кнопка `EC_manual` применяет сохранённую Manual-кривую CPU
к обоим вентиляторам. CPU=GPU включён обязательно: бит 7 регистра 0x7C5 сброшен.
Графики показывают одну общую кривую; переключение в раздельный режим заблокировано.
Программный расчёт PWM отключён, температуру для таблицы выбирает EC.
Это не программное управление по max(CPU,GPU).

Аппаратный опыт 15.10.2026: при раздельном режиме GPU оставался на 0%;
при CPU=GPU оба вентилятора реагировали на постоянные 50% и 70%.
За 12 секунд PWM ещё не всегда достигал задания. Исходные таблицы/флаги восстановлены.
Лог: tests/test_util/analysis/fan-table-ab-20261015-174412-launch.txt.

Протокол исследуется по публичным FanSlider/NUCtool; чужой код не переносился.

## Таблица

Каждый канал: Up[16], Down[16], Duty[16] в 0xF00/0xF30. Первый слот Up=0,
Duty=0 — предполагаемый маркер прошивки. Down[0] не изменяется. Пользовательские
точки начинаются со слота 1, Down=Up-3, Duty=PWM*2. При необходимости добавляется
85 °C / 100%; последний слот остаётся 255/255/200. Максимум 14 рабочих точек
вместе с защитной. Первая служебная точка и температурная реакция требуют
подтверждения на реальном EC; таблица сама по себе не доказывает охлаждение.

Офисный/другой пресет производительности сохраняется; Fan Boost выключается.
Плата, возможность RAM-управления, владение, запись и полный readback проверяются.
После применения программный температурный расчёт и запись текущего PWM
выключены. RPM/PWM остаются телеметрией; каждые 5 секунд проверяются флаги,
при расхождении восстанавливаются только FANs. Сбой чтения не означает сброс.

Default возвращает штатное охлаждение. Manual/Min/Max заменяют экспериментальный
режим обычным. Изменение пресета производительности сохраняет активный EC_manual
и повторно применяет таблицы. В пределах текущей сессии режим переживает сон;
экспериментальный признак не сохраняется на следующий запуск программы.

## Проверка

1. На простое нажать EC_manual. Дождаться подтверждения таблиц.
2. Записать температуру EC, показания PawnIO/AMD и PWM/RPM.
3. Дать короткую нагрузку CPU, затем убрать её; отдельно повторить с GPU.
4. Сопоставить переходы PWM с Up/Down. Показания PawnIO могут отличаться
   от датчика, по которому выбирает ступень EC.
5. Вернуться в Default после опыта.

В логах: EC_MANUAL TABLE, EC_MANUAL armed, EC_MANUAL OBSERVE.
0x43E — имеющийся источник CPU EC; 0x44F записывается только как сырой кандидат
GPU и не используется программой для принятия решений. Верификация записи
отделена от физического подтверждения температурной реакции.

Тест magiccontrol_ec_manual_tests работает с имитатором EC: формат таблиц,
гистерезис, служебные слоты, сохранение Office, отсутствие host-расчёта и
периодической записи таблиц, восстановление флагов, возврат Default/Manual.
