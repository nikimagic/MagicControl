# Иконка приложения и меню трея

Источник изображения: `src/gui/assets/magiccontrol-icon-full-background.png` — выбранная
пользователем крупная M с фиолетово-бирюзовым градиентом и сплошным тёмным фоном.
ICO и PNG512 созданы масштабированием этого изображения.
Windows использует ресурс ID 101, Linux — встроенный GResource.

Структура и нативное поведение меню перенесены из эталона
`C:\Users\admin\Documents\mechrevo\Fan_X15Pro\Form1.Tray.cs` и `NativeTrayMenu.cs`.

| Пункт | Действие |
|---|---|
| Открыть | Восстановить прежнее окно и вкладку; пункт Windows по умолчанию |
| Батарея | Выбрать 100%, 95% или 85% через обработчик SETs |
| Мощность | Выбрать Офисный, Сбалансированный или Турбо через SETs |
| Подсветка | Уровни 1–4; разделитель; Выкл.; цвет и эффект сохраняются |
| Выйти | Штатно завершить приложение |

Состояние меню берётся из кэша SETs; при открытии запускается фоновое обновление.
Нажатие не заменяет галочку: выбранный пункт подтверждается последующим чтением EC.
В Windows используются Shell_NotifyIcon, TrackPopupMenuEx и отдельное невидимое
окно-владелец меню. Explorer TaskbarCreated вызывает повторную регистрацию значка.

Крестик скрывает окно, не уничтожая страницы, контроллер вентиляторов и OSD.
«−» оставляет окно на панели задач. Открытие из трея сохраняет максимизацию и
активную вкладку. В Windows повторный запуск передаёт команду открытия первому
экземпляру. Выход не скрывает окно повторно, удаляет значок и выполняет обычную
очистку ресурсов, в том числе восстановление штатного охлаждения контроллером.

Linux экспортирует SNI и DBusMenu через существующую сессионную шину. Наличие
зарегистрированного хоста проверяется до скрытия окна. Без хоста обычное закрытие
сохраняется; потеря хоста показывает скрытое окно. Аппаратные подменю отключены,
поскольку Linux EC-транспорт ещё не подключён.

Реализация повторяет меню и способ открытия эталона. Политика настоящего выхода
сохраняет уже принятую в MagicControl процедуру возврата к прошивке; эталонное
оставление RAM-управления после завершения процесса здесь не вводится.
