## 2. Что стало с 30.10 → 31.10 (главное)

### A. Battery aging / capacity — новая ветка (0.1.412–421)
Серия исследований + фичи:
- дата изготовления батареи из EC cache
- **aging override** с native save/readback
- оценка ёмкости через EC charge target
- **thermal history / exposure counter**
- USB-C priority через **I2EC** (read-only probe → 0.1.419 verify → 0.1.420 **reject unsupported USB-C mode**)
- serialization battery history GUI+CLI
- **UWACPIDriver 10.48.11.331 argument corruption** — задокументировано

Это **глубокая OEM-работа**: не UI, а **firmware semantics** (age, voltage, charge target).

### B. Core ownership cutover (0.1.398–408)
```
KEYs queue/workers/completion  → out of GUI
INFO lifecycle / refresh       → unified
SETs/FANs model ownership     → centralised
GPU commands                   → unified, service не зависит от GUI
update/OSD/rotation workers   → removed from GUI
```
Плюс **аудиты** (core-architecture-audit, code-review-0.1.408, ownership traces).  
Это прямое продолжение R01: **GUI = policy/draw, platform = execute**.

### C. Wujie native-детали
- Native Default fan graphs через core resources (0.1.396–397)
- APP gate: Copilot + idle timer shared (research)
- Camera RGB/IR vs physical LED, mic mute + EC
- Copilot unified with KEYs, 11 switches audited (0.1.393)

### D. AFULNX / Linux firmware readers
- `linux-firmware-readers-20261030`: **нет public AFULNX 5.17**; ASRock 5.16.03 оригинал  
- release notes AMI 5.17: Linux supported в notes, **бинарь не в zip**
