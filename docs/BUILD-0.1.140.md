# MagicControl0.1.140 — батарея и политика EC

22.10.2026. Общий Tools/Build-All.ps1 завершён для Windows/Linux, обе рабочие
portable обновлены и сверены по версии/SHA256. После добавления декодера в
незавершённый билд выполнен Resume того же номера с пересборкой обеих ОС.

## Изменения

- Один общий Windows battery enforcement:4+ROMFF /7+owned RAM ROM04.
  Подключены точные Wujie/GM6/HYDROC адаптеры. Перед FF→04 сохраняется
  модельный owner-файл;04 без записи владения и неизвестные значения
  отклоняются. Нет Set_ROMID/других ROM-байт/FAN/APU/voltage setters.
- GM6/HYDROC включают существующие кнопкиEC, сохраняют ChargeAuto и используют
  bounded startup/resume worker. Повтор после потенциальной записи запрещён.
  Wujie сохраняет выбранный процент и существующее восстановление конфига.
- Honor сохраняет собственный HWMI. Linux не получает неподтверждённый raw writer.
- GM6 unit400!=1 больше не скрывает независимые mV/state/cycles при готовой
  батарее. Единицы ёмкости/тока, SOC и здоровье не угадываются. Неготовые
  циклы0 не выдаются за измерение. Явно неизвестное EC health не подменяется
  Windows100% или прошлым значением из кэша.
- Сырые capacity_unit/design/full/remaining всегда остаются в register log,
  включая unit0 и нули после сброса. Контекст показывает raw counts отдельно,
  изменения ёмкости содержат previous_decimal/current_decimal. Прежняя
  событийная/10с/SOC частота сохранена, дополнительного посекундного лога нет.
