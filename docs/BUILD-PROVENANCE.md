# История сборок и исходников

## 0.1.270–0.1.285

Это промежуточные сборки перехода к каталогу ресурсов. Отдельных коммитов,
сохраняющих точное дерево исходников каждой из этих версий, в истории нет.
Версия 0.1.277 была собрана в отдельной локальной копии и не устанавливалась
в основную portable-папку. Нельзя считать её побайтово одинаковой с какой-либо
другой промежуточной сборкой.

Коммит `7a82268` содержит накопленное состояние исходников и проверенные
portable-файлы **0.1.286**. Он не доказывает, какой именно поднабор изменений
присутствовал в каждой более ранней версии. Ссылки на конкретные промежуточные
бинарники, логи и их хэши нужно проверять по сохранившимся артефактам отдельно;
сам диапазон не восстанавливает отсутствующие снимки исходников.

Начиная с 0.1.286 проверенные общие сборки фиксируются отдельными коммитами.
